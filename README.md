# 📅 班級課表對照機 - 專業賽程規劃工具 (classVSclass)

這是一套專為排定體育賽程、聯課活動設計的智慧對照工具。它能自動解析 PDF 課表，並透過直觀的 Web 介面比對兩個班級的空檔，協助快速找出適合對打的時段。

👉 **[立即進入對照機 (https://jomogo0218.github.io/classVSclass/)](https://jomogo0218.github.io/classVSclass/)**

---

### ✨ 主要核心功能
*   **📡 PDF 自動解析**：不再需要人工剪貼，使用 Python 自動提取學期課表數據。
*   **🎨 Premium 視覺設計**：採用深色玻璃擬擬態 (Glassmorphism) 風格，針對大螢幕與大字體進行優化。
*   **🔍 智慧科目過濾**：
    *   **雙班體育**：自動高標橘色（最推薦對戰時段）。
    *   **藝能/社團**：支援自定義勾選可排科目，自動標記潛在時段。
    *   **正課保護**：非勾選科目自動變淡並加上刪除線，防止誤排。
*   **👩‍🏫 教師資訊整合**：科目名稱後方直接顯示該堂老師姓名，方便即時聯繫。
*   **📏 單一螢幕適配**：強制將 10 節課縮放至單一畫面內顯示，字體極大化確保高辨識度。
*   **💡 彈性檢視模式**：支援「單班預覽」與「雙班對照」自動切換。

---

### 🔧 如何更新課表？ (給開發者的教學)
1.  **資料更新**：將新的 PDF 檔案放入根目錄。
2.  **數據提取**：執行 `extract_table.py` 與 `process_data.py`。
3.  **同步雲端**：在終端機執行：
    ```powershell
    git add .; git commit -m "Update schedule data"; git push
    ```
